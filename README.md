# maximo-dataanalysis-assistant
Chat Assistant with ability to query data and produce Graphs as per user's questions.


```
What are the total labor hours spent on each failure code? → Bar Chart
How many labor hours were spent on each asset? → Pie Chart
Trend of labor hours over time → Line Chart
What is the average labor hours per work order? → Metric
Work orders with more than 5 labor hours → Table
How many labor hours were spent at each location? → Area Chart
Which failure code caused the most downtime? → Treemap

streamlit run app.py

```
